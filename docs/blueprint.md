# **App Name**: Activity Compass

## Core Features:

- Pending Activities Grid: Display a filterable grid of pending activities, including activity code, registration date, client, client type, and priority.
- Activity Description Display: Display activity details (especially the description) when an activity is selected in the grid.
- Historical Log Display: Display historical logs of actions for selected activities with details like date, action taken, and time spent.
- Activity Logging and Closure: Enable saving daily activity logs/history and closing tasks while updating the total time invested in each task.
- Form Controls: Include buttons for saving, clearing, closing the form, closing the task, and opening a new activity entry form.

## Style Guidelines:

- Primary color: A calming blue (#6699CC) to promote focus and reliability.
- Background color: Light, desaturated blue (#F0F4F8) for a clean and unobtrusive backdrop.
- Accent color: A gentle green (#8FBC8F) to highlight actions and important elements.
- Body and headline font: 'PT Sans', a humanist sans-serif to combine a modern look with a little warmth.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clear, recognizable icons for activity types and actions.
- A tabbed layout organizes 'Pending Activities' and 'Activity History' sections clearly.
